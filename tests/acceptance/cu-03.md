# Acceptance Tests — CU-03: Reportar Zona de Riesgo

**Feature:** F5 — RiskZoneModule + RiskFormBottomSheet + MapScreenBuyer + MapScreenVendor
**SDD refs:** SDD_FASE5_UBISAFE §7.2.3 · SDD_FASE2_PASO25 §5.3 (W-06, W-17)

---

## Precondiciones

1. Firebase emuladores corriendo:
   ```bash
   firebase emulators:start --project demo-ubisafe
   ```
2. API corriendo:
   ```bash
   cd ubisafe_api
   uvicorn main:app --reload
   ```
3. App en un dispositivo Android (o emulador) con GPS habilitado.
4. Si se usa dispositivo físico, ejecutar `adb reverse` para los 4 puertos:
   ```bash
   adb reverse tcp:9099 tcp:9099
   adb reverse tcp:8080 tcp:8080
   adb reverse tcp:9000 tcp:9000
   adb reverse tcp:8000 tcp:8000
   ```
5. Una cuenta de prueba con sesión activa (rol BUYER o VENDOR).

---

## SC-01 — Reporte exitoso de zona HIGH (Robo/Asalto)

**Actor:** Usuario autenticado (cualquier rol)
**Precondición:** GPS activo, mapa visible.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Pulsar FAB naranja (+) en el mapa | Se abre `RiskFormBottomSheet` con dropdown y campo de descripción |
| 2 | Seleccionar "Robo/Asalto" en el dropdown | Botón "Enviar reporte" se habilita; chip "GPS activo" muestra coordenadas actuales |
| 3 | Pulsar "Enviar reporte" | Indicador de carga aparece en el botón; sheet se cierra tras respuesta |
| 4 | Observar mapa | Aparece círculo rojo (#C62828, 35% opacidad) de radio 100 m sobre la ubicación del reporte |
| 5 | Verificar Firestore (http://localhost:4000) | Documento en `risk_zones` con `risk_level: HIGH`, `active: true`, `expires_at` ~24h |
| 6 | Verificar snackbar | "Zona reportada. Gracias." |

## SC-05 — Ruta del vendedor evita zonas HIGH

**Actores:** Vendor V + Buyer B  
**Precondición:** Zona HIGH activa entre la posición del Vendor y la del Buyer (creada en SC-01). Vendor tiene GPS activo y visibilidad habilitada.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Buyer toca marcador del Vendor en el mapa | Dialog "Solicitar parada" aparece |
| 2 | Buyer confirma la solicitud | Buyer entra en estado "Esperando respuesta del vendedor…" |
| 3 | Vendor recibe FCM → acepta la solicitud | Vendor acepta; ruta se calcula |
| 4 | Observar polilínea en el mapa del Vendor | La ruta mostrada hace un desvío alrededor del círculo rojo HIGH (evita pasar por su centro) |
| 5 | Verificar comportamiento sin zona HIGH | Si no existe zona HIGH en la ruta, la polilínea es la ruta directa habitual |
